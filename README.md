# SafeBite AI 🥗

An offline-first, open-weight AI companion built to keep my friend Ananya safe from severe food allergies and non-veg additives while grocery shopping in India.

## 💡 Built for Hacktoberfest 2026
This project analyzes packaged Indian grocery labels to instantly flag peanuts, lactose, and hidden non-veg additives (like E120 or gelatin) specifically tailored to Ananya's safety requirements.
